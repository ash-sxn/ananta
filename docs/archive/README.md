# Legacy Website Archive

The files in this directory capture the copy, data models, and markup from the
previous Project Ananta marketing site. They are preserved so the refreshed
experience can reference the original content without keeping the old codebase
online.

- `sections/` – original JavaScript modules for each marketing section.
- `data/` – amenity and feature datasets consumed by the old UI.
- `legacy-web-index.html` / `legacy-web-index-clean.html` – pre-rebuild HTML snapshots.

The static build also exposes `/archive/legacy-web-index-clean.html` so the team
can review the legacy copy while rebuilding the new experience.
